Quantum-Enhanced Last-Mile Route Optimisation

Classical side builds routes and checks constraints (capacity, time windows, traffic). QAOA (Qiskit) re-orders groups of stops; interference decides which routes survive.

1. Classical vs hybrid routes

Each colour is one vehicle. D = depot, numbers = visiting order. The hybrid starts from the nearest-neighbour routes and keeps a QAOA change only if the exact simulator confirms it is cheaper.

2. Constructive and destructive interference inside QAOA

QAOA starts with all answers in superposition. Every answer receives many "paths" (complex arrows). Where arrows point the same way they add up (constructive, probability rises). Where they point against each other they cancel (destructive, probability falls). Valid routes are boosted, invalid bit-strings are suppressed.
